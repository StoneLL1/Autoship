# Project conventions

Read existing rules before adding to AGENTS.md. Use [the project baseline](../assets/AGENTS.base.md) as a starting point, replacing its document pointers with this project's real paths and retaining applicable existing conventions.

Keep AGENTS.md short. Include document entry points and important project-specific constraints; point to discoverable verification commands instead of copying a tool's full manual. Apply [task context](../references/context.md) to keep durable decisions separate from execution history. Use the workspace and checkpoint guidance in [sessions](../references/sessions.md); preserve existing files and conventions. Keep private absolute handoff paths in the external record or local-only instructions, rather than publishing them in a shared project document.

Check available tools and verification entry points. Include substantial scaffolding in the implementation task whose outcome needs it. Ready when the next worker can find the requirements, run/check entry points and relevant conventions, and the coordinator has recorded the external handoff location. Return to the planning route.
