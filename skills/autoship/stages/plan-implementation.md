# Implementation plan

Read the confirmed product, design, flows and technical choices. Write a short plan ordered by useful, verifiable increments, with necessary prerequisites and integration checks.

Match the plan's size to the work. Simple work may need only one or two implementation tasks; split further when difficulty, uncertainty or independently verifiable outcomes justify it. Choose which tasks can share an implementation session based on related context and capacity.

Explain the sequence and important tradeoffs. Include end-to-end acceptance of the main user flows. Leave code structure and routine implementation decisions to the implementing agent.
