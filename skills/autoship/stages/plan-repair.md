# Resolve planning findings

Read the confirmed brief and existing planning review. Resolve valid findings and make the product, design, flow, technical plan and task specs agree. Keep task count and session grouping proportionate to the work.

Verify the corrected package yourself. Record a disposition for each finding and the supporting change or reason; preserve its ID and the review's original scope. Check that every acceptance scenario still maps to a task and that changed interfaces agree. Update the handoff with remaining blockers; do not dispatch another planning review. Take genuine scope changes to the user while continuing independent work. When no blocking finding or product choice remains, select a ready task and continue with [implementation](implement.md).
