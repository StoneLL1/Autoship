    自动化发生在两次 Agent 调用之间
    Skill 给方法，Agent 做工作，脚本保存事实并决定下一次调用。关键是这三层怎样接上。
    
    
    
      
    
        
    
        
    脚本把当前阶段的指引，放进提示词
    运行 autoship new / feature 后，本地 runner 成为接力入口。它沿用已安装、已登录的 Agent CLI。
    1. 读取当前阶段，而不是一次塞入全部流程invoke.mjs 读取 stages/implement.md 等；文档同步时读取独立的 autoship-docs-sync/SKILL.md。
    2. 补上这一次工作的上下文工作树路径、任务 spec、Git 基线、已有审核问题、待验项、用户补充与证据位置一起进入 prompt。
    3. 通过 Adapter 启动或恢复 AgentCodex 接入使用 codex exec / exec resume；Agent 在工作树内读 AGENTS.md、相关文档和代码，再实施任务。
    4. 解析结果，再核对实际状态脚本验证 JSON、Git 状态和约定检查；审核阶段还核对文件树没有变化。通过后才切阶段、提交或选择下一任务。
    因此，CLI 自动流程不依赖 Agent 自己“想起再调用 Autoship”。runner 的循环负责把下一阶段指令继续交给它。
    
        
    你先和 Agent 对话，Agent 再读入口 Skill
    把导出的 Skills 放入宿主支持的目录并使用入口 Skill 后，Agent 按其中的链接定位当前阶段。
    1. 安装或导入本项目的 Skillsautoship install-skills --dir /项目/.agents/skills。安装位置取决于宿主，工具不会自动改全局配置。
    2. 让 Agent 使用 autoship 处理需求入口 skills/autoship/SKILL.md 要求先读项目规则与进度，再按新项目、feature、实现或恢复选择阶段材料。
    3. 把已经确认的需求落成 brief已有讨论可交给 autoship new / feature --confirmed-brief /路径/brief.md。这项参数代表你已批准该文件的范围。
    4. 启动 runner，才进入脚本自动接力Agent 能否直接从 App 启动并持续托管进程，由宿主能力决定；当前完整自动接力基线是终端路径。
    聊天中读取 Skill 能获得流程方法；跨进程接力、预算计数和 Git 恢复由 runner 实现。CLI 会话是否显示在 App 侧栏也取决于宿主。

    接不下去时，保留现场再找路
    代码缺陷、宿主异常与中断分别处理；换会话或回退，都保留已经发生的审核和预算记录。
    
    
    
    
    产品成果：独立的工作树与本地分支
    <主仓库>/.autoship/worktrees/<run-id>/
  AGENTS.md、产品与流程文档
  tasks.md、execution.json、源代码

branch: autoship/<run-id>
    Agent 在这里开发。回退仅针对已核验的 Autoship 专用工作树；用户原有工作区保留。任务开始时的 Git 基线用于限定恢复范围。
    接力记忆：放在工作树之外
    <git-common-dir>/autoship/runs/<run-id>/
  state.json      阶段、会话、预算、检查点
  events.jsonl    状态事件
  evidence/       请求、结果、检查、失败 diff
  report.md       交付与待验报告
    任务回退不会带走这些记录。下一个会话通过任务材料和必要的交接证据接续工作，脚本同时保留会话 ID；不是依赖前一个聊天一直记住全部事情。

    流程以本地代码和运行协议为准。上方阅读器的需求、任务和问题为教学示例，不是一次真实运行的日志。
    • scripts/autoship.mjsCLI 入口、用户输入、命令分发
    • scripts/workflow.mjs澄清、确认、规划与一次规划审核
    • scripts/invoke.mjs读取阶段指引、组装 prompt、保留调用证据
    • scripts/adapters/codex.mjs启动 / 恢复已有 Codex CLI
    • scripts/runner.mjs任务循环、执行检查、单轮审核与恢复
    • skills/autoship/SKILL.md聊天入口 Skill 与阶段材料索引
    • autoship-docs-sync/SKILL.md文档同步方法，运行计数仍由脚本管理
