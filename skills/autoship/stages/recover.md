# Recover the current work

Read the task, available evidence and reported obstacle. Inspect the environment, restore usable tools or configuration within existing authorization, and resolve conflicts in restored work. Choose a compatible technical alternative when useful.

Continue the intended work and verify it. Use waiting only when an external action or product decision is actually required, stating the smallest request and what can continue. Record missing verification separately from actual defects. Preserve task scope and the existing review; do not dispatch a reviewer or change Git history.
