# Resolve planning findings

Read the confirmed brief and existing planning review. Resolve valid findings and make the product, design, flow, technical plan and task specs agree. Keep implementation task count proportionate while preserving the required session boundaries in [sessions](../references/sessions.md).

Verify the corrected package yourself. Record a disposition for each finding and the supporting change or reason; preserve its ID and the review's original scope. Check that every acceptance scenario still maps to a task and that changed interfaces agree. Update the handoff with remaining blockers; do not dispatch another planning review. Take genuine scope changes to the user while continuing independent work. When the complete package is ready, the independent review is complete and no blocking finding or product choice remains, record the planning gate as passed, select a ready task and use [sessions](../references/sessions.md) to start a fresh [development session](implement.md), or provide manual handoff if unavailable.
