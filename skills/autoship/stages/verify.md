# Revisit pending verification

Read the original task, its recorded candidate or delivered version and pending conditions. Inspect the current project and perform the checks now possible using [quality](../references/quality.md). Record the actual version, results and evidence; retain only conditions still unverified, with their next checks. Reconcile review status and acceptance before promoting a usable increment to delivered.

Report defects with evidence. For an unfinished task, use [repair](repair.md) with its existing history; for regressions after accepted delivery, use [recovery](recover.md) to create linked repair work from the current result. Successful verification alone needs no new review. Synchronize affected documents and the handoff, then continue remaining work.
